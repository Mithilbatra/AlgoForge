A bakery has `n` ovens that all start at minute 0 and work in parallel. Oven `i` finishes one tray every `t_i` minutes and immediately starts the next one.

What is the earliest minute by which **at least `k` trays** are finished in total?

### Input
The first line contains `n` and `k`. The second line contains `t_1 … t_n`.

### Output
Print the earliest such minute.
