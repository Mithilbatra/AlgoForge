A courier must deliver `n` parcels **in the given order** within at most `d` days. Each day the courier loads a contiguous run of the remaining parcels whose total weight does not exceed the van's capacity `C`.

Find the minimum integer capacity `C` that lets the courier deliver every parcel in at most `d` days.

### Input
The first line contains `n` and `d`. The second line contains the weights `w_1 … w_n`.

### Output
Print the minimum capacity.
