You are given a non-decreasing array of `n` integers and `q` queries. For each query value `x`, report the 1-based position of the first element that is **at least** `x`, or `-1` if every element is smaller than `x`.

### Input
The first line contains `n` and `q`. The second line contains `a_1 ≤ a_2 ≤ … ≤ a_n`. Each of the next `q` lines contains one query `x`.

### Output
Print `q` lines: the answer to each query in order.
