You are given an array of `n` integers and `q` queries. Each query gives two positions `l` and `r` (1-based). Print the sum `a_l + a_{l+1} + … + a_r`.

### Input
The first line contains `n` and `q`. The second line contains `a_1 … a_n`. Each of the next `q` lines contains `l` and `r`.

### Output
Print `q` lines with the requested sums.
