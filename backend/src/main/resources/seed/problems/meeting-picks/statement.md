A conference has `n` talks. Talk `i` occupies the half-open interval `[s_i, e_i)`, so a talk ending at minute `t` does not clash with one starting at `t`. You can attend only one talk at a time and must attend each one you pick from start to end.

What is the maximum number of talks you can attend?

### Input
The first line contains `n`. Each of the next `n` lines contains `s_i` and `e_i`.

### Output
Print the maximum number of talks.
