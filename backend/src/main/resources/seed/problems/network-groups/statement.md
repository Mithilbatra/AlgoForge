There are `n` computers and no cables. Then `m` cables are installed one at a time, each connecting computers `u` and `v`. After **each** installation, print the number of groups of computers that can reach each other.

### Input
The first line contains `n` and `m`. Each of the next `m` lines contains `u` and `v`.

### Output
Print `m` lines: the number of groups after each cable.
