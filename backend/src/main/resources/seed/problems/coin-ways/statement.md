You have an unlimited supply of coins of `n` distinct denominations. In how many ways can you pay exactly `S`? Two ways are the same if they use the same number of coins of each denomination (order does not matter).

### Input
The first line contains `n` and `S`. The second line contains the denominations `c_1 … c_n`.

### Output
Print the number of ways modulo `1 000 000 007`.
