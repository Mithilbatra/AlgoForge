A warehouse floor is an `r × c` grid. `.` is free floor, `#` is a shelf, `S` is your position and `E` is the exit. Each step moves to an adjacent free cell (up, down, left or right).

Print the minimum number of steps from `S` to `E`, or `-1` if the exit cannot be reached.

### Input
The first line contains `r` and `c`, followed by `r` lines of `c` characters each.

### Output
Print the minimum number of steps, or `-1`.
