A river is crossed on `n` stepping stones numbered `1 … n`. You start on the bank (position 0) and must reach the far bank (position `n + 1`). Each jump moves you forward by **1 or 2** positions. Landing on stone `i` costs `c_i`; the banks are free.

Print the minimum total cost to cross.

### Input
The first line contains `n`. The second line contains `c_1 … c_n`.

### Output
Print the minimum cost.
